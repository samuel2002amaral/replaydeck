ReplayDeck for OBS Studio - Linux

Requirements:
- OBS Studio 30.0 or newer (64-bit)
- FFmpeg shared libraries

Installation:
1. Close OBS Studio.
2. Run in terminal: chmod +x install-linux.sh && ./install-linux.sh
3. For manual installation, copy "replaydeck.so" to:
   ~/.config/obs-studio/plugins/replaydeck/bin/64bit/
4. Copy the "data" folder contents to:
   ~/.config/obs-studio/plugins/replaydeck/data/
5. Open OBS Studio and enable View -> Docks -> ReplayDeck.
