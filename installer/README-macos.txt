ReplayDeck for OBS Studio - macOS

Requirements:
- OBS Studio 30.0 or newer (macOS 12 or newer)

Installation:
1. Close OBS Studio.
2. Double-click "install-macos.command" (or run ./install-macos.command in Terminal).
3. If blocked by Gatekeeper, allow execution in System Settings -> Privacy & Security.
4. For manual installation, copy "replaydeck.plugin" to:
   ~/Library/Application Support/obs-studio/plugins/
5. Open OBS Studio and enable Docks -> ReplayDeck.
