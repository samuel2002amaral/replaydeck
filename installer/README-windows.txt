ReplayDeck for OBS Studio - Windows

Requirements:
- OBS Studio 30.0 or newer (64-bit)

Installation:
1. Close OBS Studio.
2. Run the ReplayDeck Windows installer and select your OBS Studio folder (default: C:\Program Files\obs-studio).
3. For manual installation, copy "replaydeck.dll" to:
   C:\Program Files\obs-studio\obs-plugins\64bit\
4. Copy the "data" folder contents to:
   C:\Program Files\obs-studio\data\obs-plugins\replaydeck\
5. Open OBS Studio and enable View -> Docks -> ReplayDeck.
